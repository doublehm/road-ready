# Enhanced Stitch Prompt: Mobile App UI Refinement

## 🎯 Goal
Refine the mobile user interface of the Road Ready app to maximize usability, visual hierarchy, and brand consistency for on-the-go students.

## ✨ Enhanced Prompt (Copy & Paste to Stitch)

> **"A high-end, mobile-first UI for the Road Ready student app. Maintain the 'Guardian Drive' aesthetic using the Deep Navy (#1E293B) and Forest Green (#15803D) palette on a clean white (#FFFFFF) background. 
>
> Implement a bottom navigation bar with semi-transparent glassmorphism (20px backdrop-blur) containing icons for 'Lessons', 'Explore', 'Messages', and 'Profile'. 
>
> On the home screen, feature a prominent 'Next Lesson' hero card with high-impact Manrope display typography. Use tonal layering—a white card with a subtle ambient shadow (6% opacity) on a soft gray (#F1F5F9) background—instead of solid borders.
>
> Integrate the 'Progress Ribbon' as a tactile, 8px thick track with a Forest Green fill to visualize license completion. Ensure all interactive buttons have 12px rounded corners and a slight metallic sheen to evoke a premium automotive feel."**

## 🛠️ Implementation Strategy (Incremental Precision)
Follow these steps within Stitch to apply the mobile improvements:

1.  **Mobile Foundation:** Use the prompt above to generate a new mobile variant of the primary dashboard.
2.  **Navigation Focus:** Once the layout is established, refine the bottom nav specifically: *"On the mobile dashboard, add a subtle glowing indicator above the active navigation icon in Forest Green."*
3.  **Interaction Polish:** Focus on the lesson cards: *"Refine the 'Next Lesson' card on mobile to include a 'Quick Call' button for the instructor, styled as a secondary ghost button with a navy outline."*
4.  **Feedback Loop:** Ensure success states (like completing a quiz) use a full-screen celebratory Forest Green overlay that feels encouraging and safe.
